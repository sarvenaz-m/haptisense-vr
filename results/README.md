# Generated results

Every committed result in this directory is synthetic and reproducible.

- `demo/` is produced by `haptisense demo --output results/demo`.
- `psychophysics/` is produced by `haptisense psychophysics --output results/psychophysics`.
- `comparison/` is produced by `haptisense compare --output results/comparison`.

These files demonstrate the data and analysis pipeline. They must not be
described as participant data, clinical evidence, or calibrated device output.
